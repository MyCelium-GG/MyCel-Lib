Mycel is the shared core library of the MyCelium mods: configuration, events, scheduling, networking, registration, data files and chat helpers that work the same on Fabric, Forge and NeoForge.

Getting started

Add JitPack and the library (use a release tag):

repositories {
    maven { url 'https://jitpack.io' }
}
dependencies {
    implementation 'com.github.MyCelium-GG:MyCel-Lib:VERSION'         // Minecraft 26.3
    // implementation 'com.github.MyCelium-GG:MyCel-Lib:VERSION-26.2' // Minecraft 26.2
    // implementation 'com.github.MyCelium-GG:MyCel-Lib:VERSION-26.1' // Minecraft 26.1
}

Then, from each loader entrypoint:

{@code
public static final ModMetadata META = ModMetadata.builder("mymod", "My Mod", "1.0.0").build();

public static void init() {
    Mycel.initialize();
    Mycel.registerMod(META);
    ConfigBuilder builder = Mycel.config(META);
    ENABLED = builder.booleanValue("enabled", true, "Whether the feature runs.");
    CONFIG = builder.build();
}
}

Start at {@link my.celium.org.Mycel}. Guides, examples and the player documentation live on the MyCelium wiki.

Compatibility

Mycel follows semantic versioning: within one major version, code compiled against an older release keeps working. Anything in my.celium.org.internal, and members not shown on this site, are not API and may change in any release. Deprecated members are removed only in the next major version.
